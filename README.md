# 🌟 Day One Orientation Setup

## 📌 About the Project
This project was created as part of my internship activities. It represents a Day One Orientation webpage designed to welcome and guide new interns through their initial onboarding experience.

The webpage provides an organized and user-friendly introduction to the internship orientation process.

- Practice HTML structure and web page development.
